`db-robust-clust` is a Python package implementing robust clustering algorithms — including Fast K-Medoids and Q-Fold Fast K-Medoids — designed to scale to large volumes of mixed-type multivariate data, introduced in Grané &amp; Scielzo-Ortiz (2026), *"New Distance-Based Robust Clustering Algorithms for Large Mixed-Type Data"*, published in Advances in Data Analysis and Classification ([DOI: 10.1007/s11634-026-00701-9](https://doi.org/10.1007/s11634-026-00701-9)).

It has been applied to detecting international opinion groups on the Gaza conflict from Reddit data (see [Publications]({{ "/publications/" | relative_url }})).
